# BlogCore
Es un BMS(Blog Management System) permite gestionar el contenido de multiples redes sociales desde una plataforma.

## Sobre el Proyecto
El Proyecto esta destinado a generar difusión de perfiles, dando la posibilidad de redactar publicaciones/noticias y posteriormente publicar en diferentes plataformas de forma manual o asistido por inteligencia artificial.
Permitir saber la cantidad de visitas que tiene, realizar publicaciones, vincular sus redes sociales, generar imágenes, auto publicar contenido, generar encuestas, entre muchas otras, para que usted como generador de contenido acceder a métricas de sus publicaciones, automatizar procesos repetitivos.

## Razón de existir
Existe proyecto cumple la función como experimento para generar mayor difusión a las empresas y reclutadores sobre las habilidades que tienen los profesionales asi como posicionar mejor. Brindando un espacio donde este mismo pueda explayar sus hallazgos y compartirlo con las diferentes comunidades usando un kit de herramientas que ofrece este software.

## Roadmap
Actualmente el proyecto permanece en estado publico para generar difusión en las redes y ser accesible a los curiosos, pero en un futuro este proyecto procederá a convertirse en un sistema privado que solo sera accesible a los usuarios autorizados. 

### Lanzamiento de una beta
El primer objetivo de este proyecto a cumplir es tener las funcionalidades básicas cubiertas como lo es la integración, extraccion de datos y finalmente sistema de autenticación segura. Terminada la etapa se permitirá el acceso a usuarios de prueba para que evalúen el comportamiento del sistema y brinden feedback.
![BlogCore Roadmap](https://public-bucket.pumacore.com/blogcore/public/file_000000008ee8820e92def2bdb87f599b.png)
Durante el desarrollo y analisis del feedback que se obtenga se estará definiendo una version alfa la cual tendrá mejores funcionalidades y disponibilidad a publico
