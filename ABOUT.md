# BlogCore
Centraliza tu blog en una plataforma.
Este proyecto esta destinado a generar difusión de perfiles, dando la posibilidad de redactar publicaciones/noticias y posteriormente publicar en diferentes plataformas de forma manual o asistido por inteligencia artificial.

## Actualidad
El proyecto se limita únicamente a dar difusión a la cuenta [/fveronelli](/authors/fveronelli).

## Futuro
En un futuro se tiene pensado permitir a cualquiera que este interesado en la plataforma, en caso de querer hacer un despliegue propio puede acceder a el repositorio en GitHub [BlogCore](https://github.com/Puma-Core/BlogCore) de momento se recomienda usar la branch develop la cual permitirá a usted tener una instancia similar a esta.
